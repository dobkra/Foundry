# Scope

Status: `approved_for_manual_execution`

## Approved V0.9 Scope

V0.9 is approved only as documentation/manual implementation-readiness planning for the Foundry Launcher.

## In Scope

- Create the V0.9 implementation-readiness packet.
- Record the fast-track review rule for safe documentation/manual work.
- Recommend the first implementation target.
- Recommend the first implementation mode.
- Define the first build boundary for a future approval packet.
- Identify suggested V1 MVP screens.
- Identify a suggested first technical route without implementing it.
- Preserve open decisions for Dobromir.

## Out Of Scope

- UI implementation or UI build.
- Creating React components.
- Adding app routes.
- Adding code or scripts.
- Adding automation.
- Creating Linear issues.
- Creating GitHub issues.
- Launching Codex tasks.
- Integrating Linear, GitHub, or Codex.
- Creating work folders.
- Mutating registry files.
- Adding database/server/deployment files.
- Modifying DK Arkitekter OS.

## Implementation Readiness Boundary

V0.9 may prepare the first real implementation path, but it does not approve the implementation itself.

A separate implementation packet is still required before any UI implementation, local file-output behavior, app route, code, integration, automation, deployment, registry mutation, or Codex launch is created.

## Fast-Track Boundary

This packet intentionally uses `approved_for_manual_execution` directly because it is Markdown-only and documentation/manual planning only.

No follow-up status-normalization PR should be needed for this packet.
