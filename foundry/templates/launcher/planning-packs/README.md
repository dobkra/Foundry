# Progressive Planning Pack Templates

Planning packs are optional extensions of a Foundry Launcher staging packet.

Simple work should not be forced into all packs. Larger projects may use one or more packs before Linear or Codex execution when the work needs deeper discovery, architecture, business, goals, UI/workflow, or issue breakdown planning.

Linear issues should be generated from approved scope, not used to invent scope.

ChatGPT acts as project architect and planning assistant. Codex records and later executes approved work. Dobromir is required only for direction/authority decisions.

## Pack List

- Basic Staging Packet.
- Discovery Pack.
- Architecture Pack.
- Business Functions Pack.
- Goals and Outcomes Pack.
- UI / Workflow Sprint Pack.
- Issue Breakdown Pack.

## Operating Boundary

These templates do not create UI, automation, Linear issues, GitHub issues, Codex tasks, registry updates, deployments, app routes, databases, server code, or runtime Launcher behavior.
