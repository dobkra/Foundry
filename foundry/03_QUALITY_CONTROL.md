# Foundry Quality Control

## QC Rules

- Preserve approval gates.
- Keep documentation-only tasks documentation-only.
- Update markdown links after documentation moves.
- Do not change source code behavior during documentation restructure work.
- Do not rename repositories, routes, or remotes without explicit approval.
- Preserve superseded context by archiving, not deleting.
- Record ambiguity and Dobromir review requirements.

## Step 2 Checks

- Safety precheck recorded.
- Migration map recorded.
- Content preservation log recorded.
- Link update log recorded.
- Final git status recorded.
