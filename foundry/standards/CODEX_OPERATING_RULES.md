# Codex Operating Rules

Codex is the scoped execution agent for repository and documentation tasks.

## Core Rules

- Work only inside approved scope.
- Preserve Dobromir approval gates.
- Prefer Linear for execution queue and GitHub repository files for source of truth.
- Keep documentation-only work documentation-only.
- Do not publish, deploy, release, merge, send, invoice, or activate automation without approval.
- Stop for scope ambiguity, business decisions, visual direction, client-facing content, pricing, quote logic, legal wording, privacy/security behavior, repository architecture changes, or external system changes.
