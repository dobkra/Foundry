# Repo Architecture Rules

## Target Repos

- Global Foundry: `https://github.com/dobkra/foundry`
- DK Arkitekter OS: `https://github.com/dobkra/dk-arkitekter-os`

## Rules

- Do not use Git submodules.
- Do not rename the current repo without approval.
- Do not update remotes without approval.
- Keep current repo transitional until the split is approved.
