# Support Codex Handover

## Required Context For Codex

- Active issue or support item
- Project/module owner
- Allowed files
- Forbidden files
- Reproduction steps
- Severity level
- Approval gates
- Expected output
- Required checks

## Stop Conditions

Codex must stop before external actions, destructive actions, client-facing changes, pricing/quote/legal changes, visual direction changes, deployment/release, repository architecture changes, or ambiguous scope expansion.
