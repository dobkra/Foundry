# Incident Workflow

## Incident Log Requirements

- Incident title
- Severity
- Start time and detection source
- Affected repo/project/module
- Impact
- Reproduction or evidence
- Immediate mitigation
- Root-cause notes
- Regression checks
- Approval status
- Follow-up tasks

## Workflow

1. Stabilize and prevent further damage.
2. Preserve evidence.
3. Identify approval gates.
4. Apply only approved safe fixes.
5. Record regression checks.
6. Create follow-up issues where needed.
