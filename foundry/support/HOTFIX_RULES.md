# Hotfix Rules

## Safe Codex Hotfixes Inside Approved Scope

Codex may autonomously fix:

- broken links
- build errors
- typecheck errors
- lint errors
- test failures
- documentation path errors
- low-risk internal bugs inside approved scope

## Dobromir Approval Required

Approval is required for hotfixes touching:

- pricing
- quote logic
- client-facing copy
- public content
- visual direction
- deployment/release
- privacy/security behavior
- risky data model changes
- project/module boundary changes
