# Bug Triage Rules

## Intake Requirements

- Affected project/module
- Observed behavior
- Expected behavior
- Reproduction steps
- Environment
- Logs, screenshots, or failing command output when available
- Severity estimate
- Approval gate risk

## Triage Steps

1. Confirm scope and ownership.
2. Reproduce or identify missing reproduction data.
3. Classify severity.
4. Check whether the fix is safe for autonomous Codex work.
5. Route approval-gated fixes to Dobromir review.
