# Foundry

Foundry is the execution factory. It controls standards, templates, Codex instructions, Linear/GitHub workflow, QC, audits, helpdesk/support, project architecture rules, and global execution governance.

This folder is the active Foundry documentation area inside `dobkra/foundry`.

The copy-first import from `dobkra/dk-arkitekter-os` is recorded in `FOUNDRY_IMPORT_MANIFEST.md`. DK repo cleanup and pointer replacement are deferred to Step 10C.

## Areas

- `standards/` - global operating rules and classification rules.
- `templates/` - reusable project/module templates.
- `support/` - Foundry Helpdesk / Support Layer.
- `system/projects/` - Foundry-owned system projects such as Foundry Runtime and Foundry Control Center.
- `system/workflows/` - Codex / Linear / GitHub and Paperclip / Praxion workflows.
- `project-registry/` - project registry and repo split plan.

Foundry is not DK Arkitekter OS. DK Arkitekter OS is a project under Foundry.
