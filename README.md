# Foundry

`dobkra/foundry` is the active global Foundry repository.

Foundry is the execution factory, architecture governance layer, Codex workflow system, support layer, standards library, template library, project registry, and runtime planning layer for Dobromir-managed work.

Active project repositories, such as `dobkra/dk-arkitekter-os`, remain the source of truth for project-specific implementation, business rules, source code, and project governance.

Historical inactive material belongs in `dobkra/archive`.

Main Foundry documentation starts at `foundry/README.md`.
